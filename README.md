# Ricuh Arena

Game tembak-tembakan arena 2D, satu file `index.html`. Bisa lawan komputer atau main online bareng teman.

## Cara main bareng teman
1. Kirim file `index.html` ke teman kamu, atau upload ke hosting gratis (misalnya app.netlify.com/drop atau itch.io sebagai game HTML) lalu bagikan link-nya.
2. Satu orang klik **Buat Room**. Kode 5 huruf muncul di pojok kiri atas.
3. Teman masukkan kode itu di **Gabung Room Teman**. (Kalau di-hosting, link `...?room=KODE` langsung mengisi kodenya.)

Semua pemain butuh internet. Komputer host yang menjalankan game, jadi pilih yang koneksinya paling bagus, dan jangan tutup tab host. Maksimal 10 petarung (pemain + bot).

## Main di HP
- Jangan kirim file lewat WhatsApp untuk HP: buka lewat **link** (game yang di-hosting), di Chrome/Safari, bukan di browser dalam aplikasi chat.
- Pegang HP posisi landscape. Jempol kiri = joystick jalan (dorong ke atas = lompat, ke bawah = turun). Jempol kanan = geser untuk bidik + tembak (ada bantuan bidik). Tombol SKILL, GANTI, TOKO, KARAKTER, SKOR, ⏸ ada di layar.
- Kalau tetap gagal tersambung di data seluler, coba WiFi atau hotspot dari HP lain.

## Kontrol keyboard
A/D jalan · W/Spasi lompat · S turun dari platform · Klik kiri tembak · Klik kanan/F skill · Q/E/scroll/1-9 ganti senjata · B toko · C ganti karakter · Tab skor · M suara · Esc menu · Host: +/- tambah/kurangi bot
